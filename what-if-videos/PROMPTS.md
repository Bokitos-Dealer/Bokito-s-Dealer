# Prompts for parallel sessions

Open one new Claude Code session per episode at claude.ai/code on the repository **bokitos-dealer/bokito-s-dealer**, and paste one prompt into each. Every session gets its own machine, so they render at the same time.

## Episode 2: What if the power grid failed for a month?

```
Make episode 2 of my TikTok "What if…" series (@what.if.your.life): "What if the power grid failed for a month?" (id: power-grid).
Everything is in the folder what-if-videos/ on the branch what-if-videos. Steps:
1. git fetch origin what-if-videos && git checkout -b what-if-power-grid origin/what-if-videos
2. sh what-if-videos/setup.sh
3. Read what-if-videos/PLAYBOOK.md and follow it exactly, and read the brief for `power-grid` in what-if-videos/EPISODES.md. Study scenarios/ai-jobs.js and scenarios/ai-jobs-set.js as the reference episode.
4. Research and verify the facts, write the script and voice-over, build the scenes, preview and fix framing, render, run the QA, encode.
5. Send me the finished 1080p video and a separate cover image (no cover inside the video, no end card), plus a suggested caption with hashtags and the list of sources.
Commit and push your work to the branch what-if-power-grid. Don't edit shared engine or kit files; copy what you need into your own scenario files.
```
