# Bokito-s-Dealer

## Chess Rater (TikTok / Reels videos)

[`chess-rater/`](chess-rater/) renders "I rated ___ like a chess game" short-form videos:
movie or TV clips with chess.com-style move ratings, an eval bar, AI voice-over commentary
and a closing Game Review. See [chess-rater/README.md](chess-rater/README.md).
